# Zetter Forge

[![CI](https://github.com/kongyo2/zetter-forge/actions/workflows/ci.yml/badge.svg)](https://github.com/kongyo2/zetter-forge/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/kongyo2/zetter-forge)](https://github.com/kongyo2/zetter-forge/releases/latest)
[![License](https://img.shields.io/github/license/kongyo2/zetter-forge)](LICENSE)
[![PRs welcome](https://img.shields.io/badge/PRs-welcome-brightgreen)](CONTRIBUTING.md)
[![CodeRabbit Pull Request Reviews](https://img.shields.io/coderabbit/prs/github/kongyo2/zetter-forge?labelColor=171717&color=FF570A&label=CodeRabbit+Reviews)](https://coderabbit.ai)

Zetter のキャスト設定をパソコンに保存して、手元で書き直すためのデスクトップアプリです。Zetter に載せる前の下書き、載せたあとの控え、手元での改良に使います。

![キャラクターの編集画面。左に保存したキャストの一覧、真ん中に設定の欄と、登場人物ごとの字数を原稿用紙のマスで示す枠、右に Zetter で完成するときの確認が並ぶ](docs/screenshots/editor.png)

Zetter のキャスト作成画面と同じ項目・同じ上限で書けます。右側の「Zetter で完成するときの確認」に、Zetter で止められる点や保存されない点が出ます。

![「Zetter へ写す」のタブ。22項目のうち4項目が済み、1項目はコピーしたあとに書き換えたことを示している](docs/screenshots/transfer.png)

「Zetter へ写す」のタブでは、Zetter の作成画面と同じ順に1項目ずつコピーできます。コピーしたあとに書き換えた項目も分かります。

![暗い色で表示したキャラクターの編集画面](docs/screenshots/editor-dark.png)

パソコンの設定に合わせて、暗い色の画面にもなります。

## 貢献してくださった方

不具合の報告やプルリクエストなどで、Zetter Forge に関わってくださった方です。ありがとうございます。
