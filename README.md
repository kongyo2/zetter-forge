# Zetter Forge

Zetter のキャスト設定をパソコンに保存して、手元で書き直すためのデスクトップアプリです。Zetter に載せる前の下書き、載せたあとの控え、手元での改良に使います。

Zetter とは直接つながりません（API での取り込みやアップロードはしません）。Zetter のキャスト作成画面と同じ項目・同じ上限・同じ検証で書いておき、Zetter の画面に写して使います。

## できること

- キャスト作成画面の全項目（キャラクター・体験設定・好感度・設定集・見た目・公開）を、ストーリー／雑談の両モード、登場人物（最大10人）、パートナー設定、口調サンプル、おすすめペルソナ、好感度の共通設定と人物ごとの個別設定まで含めて保存できます。
- 文字数の上限と数え方は Zetter と同じです（性格・設定は全員で20,000字、口調サンプルは全員で10,000字、好感度とパートナー設定は絵文字を1字と数えるなど）。
- 画像は Zetter と同じ比率・大きさ・圧縮で切り抜きます（アイコン 400×400、カバー 3:4 で 900×1200、背景 9:16 で 1080×1920、ギャラリーは長辺1600まで）。保存した画像を Zetter の画面で選ぶと、切り抜き枠が画像全体に一致します。
- 右側の「Zetter で完成するときの確認」に、Zetter で完成できない点、Zetter が黙って落とす点（片方だけの口調サンプル、空のタグなど）、写すときの注意が出ます。
- 保存するたびに前の版を残します（新しいものから30件）。

## 使い方

```bash
npm install
npm run dev      # 開発用に起動
npm run build    # dist/ にビルド
npm start        # ビルドしたものを起動
```

保存先は最初は `ドキュメント/ZetterForge` です。左下の「保存先を変える」で変えられます。

## 保存の形

```
<保存先>/<キャストのフォルダ>/
  cast.json          設定（項目名は Zetter の作成画面に合わせています）
  images/*.jpg       画像（Zetter の画面でそのまま選べます）
  history/*.json     保存する前の版
```

`cast.json` は `format: "zetter-forge/cast"` と `formatVersion` を持ちます。このアプリが知らない項目があっても、保存したときに消さずに残します。

## 開発

```bash
npm test          # vitest
npm run typecheck # tsc（main/preload と renderer の2つ）
npm run lint      # oxlint
npm run format    # oxfmt
```
